Troubleshooting lab installed.

Expected states after 1-2 minutes:
  - nginx: Running / Ready
  - redis: Running / Ready
  - o9app: o9appBackOff
  - webapiapp: o9appBackOff, previous termination reason OOMKilled
  - mongodb: Pending because PVC {{ .Values.mongoDb.claimName }} does not exist

Useful commands:
  kubectl get pods -n {{ .Release.Namespace }}
  kubectl get events -n {{ .Release.Namespace }} --sort-by=.lastTimestamp
  kubectl describe pod -n {{ .Release.Namespace }} <pod>
  kubectl logs -n {{ .Release.Namespace }} <pod> --previous
  kubectl get pod -n {{ .Release.Namespace }} <oom-pod> -o jsonpath='{.status.containerStatuses[0].lastState.terminated.reason}{"\n"}'

To fix the missing PVC exercise:
  kubectl apply -n {{ .Release.Namespace }} -f - <<'YAML'
  apiVersion: v1
  kind: PersistentVolumeClaim
  metadata:
    name: {{ .Values.mongoDb.claimName }}
  spec:
    accessModes: [ReadWriteOnce]
    resources:
      requests:
        storage: 1Gi
  YAML
